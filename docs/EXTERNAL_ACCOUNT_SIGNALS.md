# External-account signals — experimental 2026-11-16

Owner explicitly requested Desk model execution against the API-connected simulation account. This scoped extension preserves ADR-004: FQE evaluates the frozen typed graph; Desk owns the existing Trading API integration. This does not close P4-03.03 or accept general venue/live trading.

The private stdio peer advertises optional `signals.external-account/1`. `signals.open` accepts exactly `model` (composition v3 JSON object), compiles one process-owned graph and returns `handle`. Only one signal session is admitted; it is independent of managed historical runs. `signals.close` accepts `handle` and releases it. EOF drops all signal state. The FFI/stateless dispatcher does not advertise this process-owned capability.

`signals.advance` accepts exactly `handle,bars,account,positions,decision`. `bars` contains 1..1000 ascending exact-decimal OHLCV records, each exactly `time_ns,open,high,low,close,volume`; timestamp is the completed bar close. A trading decision accepts exactly one bar. Inputs bind one selected symbol/timeframe; secondary source shapes reject. Account values and leg values are supplied external decimal slots, not native simulated balances. Each leg is exactly `symbol,side,values,entry_node`; Desk sends only uniquely confirmed session-owned holdings. `entry_node` associates actual fill average with the compiled entry rule's protection. Warmup uses decision=false and publishes no historical intent. Desk omits historical account slots rather than inventing prior account balances.

Native indicator/crossing/state instances persist across calls. Output is `last_ns,intents`, containing each fired action's resolved settings, typed input values, source node/kind and timestamp. It contains no fill, cash ledger or performance report. Native price/percentage stop-loss and take-profit inspect close against actual external average entry price. A protection exit suppresses same-leg action/reopening on that bar. Desk admits only its faithfully mapped market-order profile; unsupported order/protection/source semantics reject before broker submission. No HTTP, credentials or trading SDK implementation is added to FQE.

Nonascending/duplicate input and malformed OHLCV reject. Any failed advance invalidates the graph session instead of permitting ambiguous stateful replay. Numeric/graph errors use existing strict checked Decimal and native errors. No automatic session recovery, persistent ownership, partial-fill adoption, external broker order-ID correlation or reconnect catch-up is claimed. Desk stops new actions when account identity, market/product or model changes, when funding cannot be read, or when a new-bar gap/staleness is detected. Existing manual positions are excluded from automatic close ownership.

Acceptance: tests/live_signals.rs covers actual SMA golden signals at bars5/7; historical warmup suppression; no stale edge at bar6; duplicate rejection/session invalidation; source mismatch; OHLCV errors; actual-entry-price percentage stop and take profit with no same-bar reentry. Workspace fmt/check/test/strict Clippy and release build run locked/offline. Desk paired tests use the real peer plus a mock broker before the authorized simulation-account desktop test. Full observed evidence belongs to the consuming Desk acceptance note. No dependency/lock changes, installation, external graph upload or publication.
