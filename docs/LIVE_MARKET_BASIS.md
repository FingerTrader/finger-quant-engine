# Native live market basis extension

Date: 2026-11-16. Optional experimental capability `signals.multisource/1` accompanies `signals.external-account/1`; existing historical financial profile stays independent.

`signals.open {model}` compiles the entire native graph. Data nodes are `bars` (OHLCV) or `quotes` (close/ask/bid/mid prices). Each node has a nonempty dataset stream key, inherited or explicit symbol, timeframe (quote: rt) and positive maxAgeSeconds. One stream key may be shared only by identical kind/symbol/timeframe; at most 16 streams. The host binds these keys to actual data. Only one external-account session may be open. The legacy `signals.advance` remains for a single bar source.

`signals.advance_multi {handle,time_ns,events,account,positions,decision}` accepts one to sixteen unique stream updates. Each event is `{stream,sample_ns,values}`. All timestamps are exact integer nanosecond strings. Decision clock increases strictly; source samples increase strictly per stream and cannot be later than decision time. Events can arrive from different source clocks without rewinding evaluation time. Updated source age is checked for trading decisions; stale cached sources produce Missing outputs through graph as-of rules. Any failed advance invalidates the handle, preventing ambiguous retries.

Bars carry exact decimal-string open/high/low/close/volume. Quotes carry exact decimal-string close/ask/bid; native midpoint is (ask+bid)/2. Prices are positive, bid <= ask; OHLC envelopes and nonnegative candle volume are checked. Indicator providers consume each new source stamp once. Repeated evaluation from a different source does not resample a slow indicator. Cross events are pulses, evaluated against prior available values; AND/OR require valid operands and use latest nonexpired source values. Quote indicator lengths count accepted quote samples, never minutes or cumulative volume. Existing temporal nodes count graph decision events; this does not add a separate per-temporal-node clock selector.

`decision:false` advances native indicator/condition state for warmup and suppresses all intents. Account and strategy-owned position snapshots remain external. Native emits intents, never fills, ledger state or HTTP requests. Existing protections use actual supplied entry price and freshest changed symbol price, preferring quote on tied timestamps. The host is responsible for serial delivery, transport freshness, source-to-market identity, ownership, sizing, broker rejection and fill reconciliation. Session close is idempotent. No reconnect catch-up, durable ownership or unsupported broker order type is implied.

Historical research `prepare` rejects quote nodes with `research_quote_history_required`; OHLCV must not impersonate quote history. Current Desk 10m transport aggregates ten complete UTC-aligned real 1m bars. Tests are in `crates/fqe-bridge/tests/live_signals.rs`; all ten scenarios and full 395-test workspace passed with fixed offline toolchain. No dependency changes.
