[Official published advisories](https://github.com/dart-lang/sdk/security/advisories?state=published) reviewed: [GHSA-frr6-h895-5pxp](https://github.com/dart-lang/sdk/security/advisories/GHSA-frr6-h895-5pxp) is a high-severity TLS trust issue explicitly excluding macOS/iOS/web. This is a scoped execution assessment, not a claim that the old SDK or all platforms are vulnerability-free. Actual Flutter plugin/native build and final distribution require separate review; no existing Desk package scripts execute in this experiment.

Dart candidates use only SDK `dart:ffi`, `dart:io`, `dart:isolate`, `dart:async`, `dart:convert`, `dart:typed_data`; `--disable-dart-dev` bypasses Pub/DartDev updater. Native code built here is first-party reviewed bridge code. The C ABI export attribute needs a narrowly isolated unsafe-code lint exception in this bridge crate; core/IR/runtime retain `forbid`. No unsafe block, raw-pointer dereference or third-party native binding generator is introduced. FFI memory remains trusted host memory, not hostile-code isolation.
