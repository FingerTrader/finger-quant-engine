# Extended native research profile

Owner-approved 2026-11-15. Experimental optional `research.graph/1`, separate from legacy Event/Workflow/cash-long source and report profiles. This is a scoped extension of DESK_UNIFIED_AUTHORING.md, not a completion claim for P4-03 or its children. Source model is a bounded typed graph derived atomically from the same Desk semantic project; native compilation validates every node, wire, setting, parameter and pure-function AST. Layout is excluded. Unknown or unrepresentable semantics reject. Original authoring remains available unchanged.

The native profile owns data visibility, pure computation, order lifecycle and accounting. Shared-currency, exact-money-step instruments share one funded cash hub; per-instrument/direction VirtualLedger accounts transfer funds through paired native Funding postings. Gross-basis restricted-short accounting is reused. Short sales retain proceeds; new positions require fully funded collateral (no invented leverage/borrow/derivative profile). `margin` in current Desk authoring enables the restricted-short research profile, not broker leverage. Net rejects implicit reversals; hedge keeps distinct long/short legs. Cross-currency conversion is outside this version and explicitly rejects.

All prices and monetary expressions use checked decimal arithmetic; precision/rounding is explicit. Orders use instrument tick/lot/money steps. Decisions occur only on the configured primary closed-bar clock. Secondary streams use latest closed bar at or before decision time, with bounded staleness; absent/expired inputs are not false and cannot fire NOT or stale crossing signals. Source indicators advance once per source event, not once per primary decision. Simultaneous closes publish before the primary decision; next opens at that timestamp occur afterwards. Fills use that opening price and prior closed volume only; high/low is never used to fill an order from the same bar. Limit/stop/stop-limit are conservative opening-only orders, not intrabar touch simulation. IOC/FOK apply at first eligible open; GTD is measured in target instrument bars. Protective conditions use closes and submit reduce-only orders for a subsequent eligible open, matching Desk authoring help.

Financial results contain native snapshots/receipts, per-leg journals and aggregate metrics. Playback reads saved snapshots and never reruns the graph or reconstructs a client ledger. Unknown result profiles reject. Cancellation preserves a truthful completed prefix and cancels pending orders. Bounds and actual acceptance are recorded with the implementation; planned optimizer/scale capabilities cannot be advertised until implemented and verified. Existing accounting algorithms and economic fixtures remain unchanged. The HistorySpec whitelist additively accepts 3m/2h/6h/12h/1w with exact duration checks; its single P3 source pin was explicitly reviewed and updated (no golden rewriting). Financial source identity therefore changes. Research identities also pin all four new implementation files through bridge identity.


## Native wire and supported graph

`research.describe` is optional capability `research.graph/1`; optimizer capability is `research.grid/1`. Both enter the same existing `run.start/status/cancel/result/result_chunk/release` lifecycle. Old Event/Workflow artifacts and original `.fqe` authoring are retained without fallback or reinterpretation. New Desk production freezes use `kind:research`; an unavailable capability rejects before execution.

The input has exactly `kind,model,streams,main,run,seed`. `model` is the UTF-8 JSON string of `desk.strategy-composition` v3; pure functions add their typed, bounded `ast` derived from the same body. Layout is excluded. Each stream has exactly `id,history_spec,csv,start_ns,end_ns,warmup_bars`, using existing HistorySpec/CSV validation. All graph settings, wires and unused nodes validate; parameter references preserve units and optimized ranges validate independently. The main stream must match the context symbol/timeframe; each data node must match its bound stream. Conflicting histories for the same symbol/timeframe reject.

All 32 Desk node kinds are native: bars/constants/parameters; SMA/EMA/RSI/MACD reuse reference providers; BOLL/ATR/rolling highest/lowest; typed arithmetic/scaling/comparison/crossing; AND/OR/NOT; delay/wait/consecutive; account/position/risk quantity; pure functions; entry/exit/cancel. Missing inputs remain unavailable. Delay alone may cut a feedback cycle. Functions support lazy if, arithmetic, comparison, boolean operators, min/max/abs/clamp/negate, without filesystem, networking or external code execution. Expressions use checked scale-12 decimals; broker prices/quantities/money align to the instrument specification.

Orders support long/short, net/hedge, open/add and all/quantity/percent reduction, dynamic quantity and limit/stop inputs, market/limit/stop/stop-limit, GTC/IOC/FOK/GTD, order tags and cancellation. Add limits and cash caps are explicit. Percentage/ATR/absolute/trailing protection is close-based and submits reduce-only subsequent-open orders. Prior execution-stream volume bounds fills. Fractional-bps costs round by instrument tick/money policy. Shorts retain proceeds and gross-basis collateral; there is no leveraged broker margin/liquidation model in this profile. Insufficient cash rejects an order truthfully. Live execution, cross-currency portfolios, intrabar touch fills, arbitrary Python and market distribution services remain outside this optional profile.

## Optimization and boundaries

`kind:research_optimization` contains exactly training and validation research inputs. `research.grid/1` validates matching strategy semantics with only dataset bindings changed, later disjoint validation data, maximum 4 optimized numeric dimensions, 32 choices per dimension, 100 trials and 200000 total source bars (`training bars * trials + validation bars`). Training alone ranks checked-native total_return or max_drawdown_ratio with stable-first ties. The winner runs once on validation. The report labels its root metrics/frames as the training winner and nests independent validation. Cancellation never exposes an applicable successful winner.

Each research run permits 16 streams, 20000 total continuous source bars, 200 nodes, 4096 wires, 256 parameters, 64 functions, 1024 orders/4096 fills and native ledger entry quotas. The transport permits 4 MiB requests and 16 MiB responses; original financial report encoding keeps its old 4 MiB bound. Full financial curves/frames are retained; debug observations retain the last 256 decisions and declare that window. Quota failures reject instead of joining independent financial runs. Managed progress remains the existing indeterminate-batch profile; no invented per-trial live progress.
